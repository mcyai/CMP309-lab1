Purpose of This Website

This website is a fictional coffee roastery created for the CMP309 Web Programming course. It demonstrates semantic HTML5 structure, tables, forms and media, all without any CSS or JavaScript.

The roastery was founded on March 15, 2020 with a simple goal: to make great coffee accessible to everyone.
