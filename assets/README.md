# CMP309 Lab 1

Muhammed Çağrı Yıldız

In this assignment I made a 4-page website using only HTML (no CSS or JS).

## Theme

I chose a made-up coffee shop called "Bean There Coffee Roasters".

## Files

- assets/index.html - home page
- assets/about.html - about page
- assets/services.html - services table
- assets/contact.html - contact form
- assets/ - everything is inside this folder: the 4 html files and the images (3 svg files)

All pages are linked to each other from the menu, and the links use relative paths.

## Challenges

- I had to copy the menu into every page by hand because there is no CSS/JS.
- It was a bit hard to pick which semantic tag to use where.
- Instead of finding images, I drew simple svg ones myself.
